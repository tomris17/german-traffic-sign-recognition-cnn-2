This repository implements a deep learning Convolutional Neural Network (CNN) architecture to classify traffic signs from the German Traffic Sign Recognition Benchmark (GTSRB) dataset.

---

## 📊 Project Overview
* **Objective:** Train an image classification CNN model to accurately identify and categorize various traffic sign types.
* **Key Steps:**
  * Image preprocessing, normalization, and resizing pipeline.
  * Convolutional Neural Network (CNN) architecture design with Conv2D, MaxPooling, Dropout, and Dense layers.
  * Model training, validation, and accuracy/loss optimization.
  * Interactive web dashboard deployment via **Streamlit** for real-time sign prediction.
